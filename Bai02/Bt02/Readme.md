## 2. Tên ứng dụng
LearningApp - Ứng dụng học tập

## 3. Giới thiệu ứng dụng
Ứng dụng LearningApp được xây dựng bằng React Native trên Expo Snack.

Trang chủ ứng dụng gồm:
- Lời chào và thông tin sinh viên.
- Thống kê khóa học.
- Danh sách môn học.
- Thanh menu giả lập cuối màn hình.

## 4. Các component
- App.js: Ghép các component tạo trang chủ.
- Header.js: Hiển thị lời chào và thông tin sinh viên.
- StatCard.js: Hiển thị thống kê khóa học.
- CourseCard.js: Hiển thị danh sách môn học.
- BottomMenu.js: Hiển thị thanh menu giả lập.
